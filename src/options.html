Leave empty or set to 0 to never close tabs. Pinned and active tabs, and tabs in the --- group, are never closed. With no --- group, nothing is closed. Any group titled with only dashes counts, like - or —.

The "Copy the current tab's URL" shortcut needs permission to write to the clipboard. Chrome asks the first time you use it, or you can allow it here: Allowed.

To change keyboard shortcuts, go to chrome://extensions/shortcuts.
